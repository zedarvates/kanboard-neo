# AGENTS.md

Guidance for AI agents working in this project. (Generated by Botte Secrète —
edit freely.)

## Session bootstrap
- Before project work, verify that Kanboard Neo is reachable.
- On Linux/macOS run `scripts/ensure-kanboard-running.sh`.
- On Windows run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/ensure-kanboard-running.ps1`.
- The launcher is idempotent: it performs a health check first and starts the
  existing Docker Compose stack only when the service is stopped.
- Never restart the computer. Do not restart a healthy container.
- Set `KANBOARD_AUTOSTART=0` to opt out for a session.
- If Docker is unavailable, report the blocker and continue with safe work that
  does not depend on the running service.

## Setup & commands
- Start/health check: use the platform launcher above.
- Build container: `docker compose -f docker-compose.sqlite.yml build`
- Unit tests: `./vendor/bin/phpunit -c tests/units.phpunit.xml`
- Integration tests: `./vendor/bin/phpunit -c tests/integration.phpunit.xml`
- Lint: `composer lint`

## Workflow contract
- Default columns: Triage → Backlog → Started → In Review → Done → Canceled.
- Agents report a concrete result, blocker, next action, project and status.
- Use `MISSION.md` for objective, constraints and success criteria.
- Use `PLAN.md` for steps and files. Keep reports concise and evidence-based.
- Do not merge or publish while required CI checks are failing.

## Conventions
- Prefer the smallest change that works; don't cut validation, error handling,
  security or accessibility.
- Route cheap work (classification, extraction, short summaries) to local models
  via the `botte-llm` MCP tools (auto_route / local_chat) to save cloud tokens.
- Pick tools with `find_skills` before reaching for the cloud model.

## Botte Secrète policy
This project follows `.botte/policy.md` (prefer local models for cheap work,
improve prompts locally, run `/checkup` after updates). Read it.
